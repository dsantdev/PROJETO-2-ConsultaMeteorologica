**Projeto de Consulta Meteorológica**

Aplicação web que permite pesquisar cidades de todo o mundo e consultar as condições climáticas atuais e a previsão para os próximos cinco dias. Os dados são obtidos da API pública Open-Meteo, por meio de duas requisições dependentes: geocodificação da cidade e consulta do clima.

- Funcionalidades:
Pesquisa de cidades com seleção entre localidades semelhantes
Painel com temperatura, sensação térmica, umidade, vento e condição do tempo
Previsão diária com temperaturas mínima e máxima e probabilidade de chuva
Lista de cidades favoritas salva no navegador (localStorage)
Mensagens de carregamento, erro e ausência de resultados

- Tecnologias:

HTML, CSS e JavaScript (fetch, async/await, manipulação do DOM e localStorage)

- Créditos:

Dados meteorológicos fornecidos por Open-Meteo.
